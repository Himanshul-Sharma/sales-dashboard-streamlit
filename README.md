# Interactive Sales Analytics Dashboard

## Project Overview
This project is an interactive sales analytics dashboard built using Python, Streamlit, Pandas, and Matplotlib. It helps users explore sales performance by product and city.

## Features
- Displays total revenue, units sold, sales records, and average sale value.
- Filters sales data by city and product.
- Visualizes revenue by product and city.
- Displays a detailed sales data table.
- Allows users to download filtered data as a CSV file.

## Technologies Used
- Python
- Streamlit
- Pandas
- Matplotlib

## How to Run

1. Install Python.
2. Install the required libraries:

   `python -m pip install streamlit pandas matplotlib`

3. Open the project folder in VS Code.
4. Run the dashboard:

   `python -m streamlit run app.py`

5. Open the local URL displayed in the terminal.

## Dataset
The dashboard currently uses sample sales data created within `app.py`. The dataset is intended for demonstration and practice.
